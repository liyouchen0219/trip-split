# 旅伴分帳

**[直接開啟網站](https://liyouchen0219.github.io/trip-split/)**

以 AI 協作開發的旅遊共同記帳 Web App。前端為單一 index.html，內嵌 CSS 與 JavaScript；多人同步使用已部署的雲端 API 與資料庫。

## 功能
- 分享邀請連結，多人各自新增與管理共同支出。
- 均分、個人加點、份數、百分比、指定金額五種分攤方式。
- 個人加點：315元三人分，小安加蛋15元，結果115／100／100。
- 搜尋支出、篩選付款人、編輯與刪除、管理旅伴。
- 結算誰應付給誰，支援全額／部分還款與撤銷紀錄。
- 最近帳本、未送出草稿保留、多人修改衝突保護。
- 響應式手機介面。

## 使用
建立旅程與旅伴 → 分享邀請連結 → 填寫誰付了什麼、誰參與分攤 → 查看結算 → 完成實際轉帳後登記還款。

## 技術說明
GitHub Pages提供靜態前端，雲端API提供共用帳本同步。前端沒有包含資料庫密鑰，也沒有包含任何私人帳本的邀請連結。持有邀請連結者可編輯該帳本，請只分享給同行者。本機帳本清單及草稿不會自動同步到其他裝置。

## AI協作與驗證
從需求討論、規格整理到程式實作與操作測試均由AI協助。反覆修正分攤尾差、建立按鈕、帳本切換入口、多人修改覆蓋、草稿遺失等問題。已實測兩個頁面共同記帳、還款歸零、部分還款、個人加點與修改衝突；運算測試涵蓋271種尾差案例。
